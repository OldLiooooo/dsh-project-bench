概述

TencentDB Agent Memory 新增 DeepSeek Harness（DSH）桌面端接入支持，将记忆能力扩展至 DSH，支持开发者在已接入的 IDE、命令行工具和桌面应用之间复用工作经验。

Agent 记忆服务

Agent 记忆服务（TencentDB Agent Memory）由腾讯云数据库团队自研，是面向智能体的独立上下文管理基础设施，提供上下文压缩、四层记忆与团队记忆管理能力。通过识别任务关键信息、压缩冗余内容，减少 Token 消耗与模型调用成本；通过自动沉淀、按需召回与权限管控，让智能体跨会话延续用户与业务背景，跨任务、跨团队复用知识与经验，减少重复沟通、搜索与试错，提升任务执行与团队协作效率。
