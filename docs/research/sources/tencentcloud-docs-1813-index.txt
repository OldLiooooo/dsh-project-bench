腾讯云数据库 AI 服务
腾讯云数据库 AI 服务（TencentDB AI Service）是腾讯云推出的新一代 AI Agent 数据库智能运维平台，由 DatabaseClaw 与 Agent Memory 两大模块构成。基于大语言模型与可插拔 Skill 体系，沉淀腾讯云资深 DBA 实战经验，支持 DBA 以自然语言完成数据库诊断、巡检与慢 SQL 分析，并为 AI Agent 提供四层渐进式记忆、上下文卸载、Skill 进化与团队记忆共享能力。广泛适用于智能运维、Agent 记忆管理、长周期协作及私域知识问答等场景。
