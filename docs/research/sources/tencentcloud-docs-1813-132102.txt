本文旨在指导您如何快速开通、部署并体验 Memory 服务，涵盖服务开通、连接凭据获取、会话写入及记忆检索等核心流程。
一、申请腾讯云账号
已注册腾讯云账号并完成实名认证。
如需注册腾讯云账号：请单击 注册腾讯云账号 。
如需完成实名认证：请单击 实名认证 。
二、新建 Memory
使用腾讯云账号登录 Agent Memory 控制台页面。单击 新建 Memory， 进入 Memory 配置页面，如下图所示。根据界面提示要求，指定 Memory 的实例名称、描述等信息，单击右下角的 立即购买 ，等待任务执行完成。具体操作，请参见 新建 Memory 实例 。
三、获取 Memory 连接凭据
在实例列表中，单击目标实例卡片。在 API 接入 区域获取 Memory 访问地址 ，单击 获取密钥 ，系统将自动生成并展示用于 API 调用的鉴权密钥（API Key）。具体信息，请参见 查看 Memory 实例 。
四、通过 SDK 接入
获取 tencentdb_agent_memory_sdk_python ，并执行 pip install tencentdb-agent-memory-sdk 安装，通过 SDK 将长期记忆能力嵌入对话流程中。
接入类型
说明
自研 Agent 接入
适用于使用 Python/Go 等语言自主开发 AI 系统的开发者。直接调用官方原生的 SDK 接口，将长期记忆的读写、检索能力深度嵌入到业务对话的主流程中。
