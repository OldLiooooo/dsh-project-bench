常见问题
云数据库 Agent Memory（TencentDB Agent Memory）当前正式商业化的计费模式为按量计费。实例开通后，系统将根据您实际产生的模型调用算力与记忆数据存储消耗，按小时进行结算，无需预先购买或预留资源，能够有效适配不同业务在用量规模与波动程度上的差异。
说明：
公测期间，已获白名单资格的账号可继续沿用包年包月免费态（限免至 2026-08-15），不涉及按量出账。
计费模式
按量计费是一种先使用、后付费的计费模式，其核心特点如下：
先使用后付费 ：实例开通后，系统将根据您实际产生的记忆数据存储与模型调用消耗，按小时进行结算并从账户余额中扣费，无需预先购买或预留资源。开通前请确保账户余额充足，以免因欠费导致服务中断。
按需使用算力 ：模型调用产生的算力（Credit）默认按实际用量进行实时统计与按小时出账，能够平滑承接业务高峰期的波动型或重度算力消耗，平滑保障您的业务连续性。
无固定到期 ：实例开通即用、无固定到期时间，持续运行即持续计费；主动销毁后进入回收站保留 15 天，期间资源占用与存储费用继续累积，回收站期间支持恢复（恢复后记忆数据、API Key、访问地址完整保留），15 天后自动销毁、无法找回。欠费停服后的处理详见 欠费说明 。
计费项说明
按量计费从实例开通时刻起按小时结算，对记忆存储与算力（Credit）两项独立计量、分别出账。

常见问题
如果我的账户欠费了，服务会被立即中断吗？我的记忆数据会丢失吗？
不会立即中断，记忆数据也不会立即丢失。账户欠费后，系统按“持续计费 → 回收站保留 → 彻底销毁”三个阶段递进处理，并在各阶段间预留充足的充值缓冲与恢复窗口。具体信息，请参见 欠费说明 。
